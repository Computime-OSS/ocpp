# Support

This file explains what kind of support is available for this repository and how to get help.

---

## Scope of support

This repository provides an open-source OCPP integration for Home Assistant.

Support in this context includes:

- Guidance on installation, configuration, and usage of the integration
- Clarification of expected OCPP behavior in supported scenarios
- Help with troubleshooting integration-level issues
- Documentation-related questions and improvement suggestions

---

## Where to ask questions

- General questions and usage help: [GitHub discussions](https://github.com/lbbrhzn/ocpp/discussions)
- Bug reports and reproducible issues: [GitHub issues](https://github.com/lbbrhzn/ocpp/issues)
- Documentation and troubleshooting references:
  - [`docs/support.md`](./docs/support.md)
  - [Read the Docs site](https://home-assistant-ocpp.readthedocs.io)

---

## What is not supported

This repository does not provide:

- Guaranteed SLA-based response times
- Vendor-specific firmware support for proprietary chargers
- Device-side implementation support for non-compliant OCPP stacks
- Commercial integration services

---

## Security reports

Do not use support channels for security vulnerabilities.
Follow the process described in [`SECURITY.md`](./SECURITY.md).

---

## Notes

Support is best-effort and community-driven.
Providing community support here does not prevent anyone from offering separate commercial support.
