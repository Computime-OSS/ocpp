# Documentation

This folder contains all project documentation.
Changes are automatically published to [readthedocs](https://home-assistant-ocpp.readthedocs.io) and the
[wiki](https://github.com/lbbrhzn/ocpp/wiki).

**Integration version described by this documentation:** **0.8.0** (see [`custom_components/ocpp/manifest.json`](../custom_components/ocpp/manifest.json)). When you bump the manifest version, update [changelog.md](changelog.md) and the version line in [index.rst](index.rst).

The top-level file for Read the Docs is [index.rst](index.rst).

The top-level file for the wiki is [Home.md](Home.md).
