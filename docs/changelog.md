# Changelog

All notable changes to this OCPP Home Assistant integration are recorded here.

Versions follow [Semantic Versioning](https://semver.org/) and match the `version` field in [`custom_components/ocpp/manifest.json`](../custom_components/ocpp/manifest.json). During the initial release phase, versions stay in the **0.x.y** range; the first **1.0.0** release is reserved for the end of the initial release milestone.
